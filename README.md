# p-t2

[Source](https://github.com/Up-to-code/p-t2) · [Issues](https://github.com/Up-to-code/p-t2/issues) · [Project directory](https://github.com/qentrah/.github/blob/main/profile/PROJECTS.md)

## Technology

React, Vite, TypeScript.

## Get started

```sh
git clone https://github.com/Up-to-code/p-t2.git
cd p-t2
```

Requires Node.js and npm.

```sh
npm ci
npm run dev
```

## Available commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | Development server |
| `npm run build` | Build the project |
| `npm run typecheck` | Check types |
| `npm run lint` | Check lint rules |
